# Teachers Day Tribute React Demo

## Run locally
1. Install Node.js.
2. Open this folder in VS Code terminal.
3. Run:
   npm install
   npm run dev

## Create a production build
npm run build

The `dist` folder can be deployed to Vercel, Netlify, GitHub Pages, or any static hosting service.

## Customize
Edit `src/main.jsx`:
- Replace teacher names
- Replace image URLs
- Replace individual matter
- Replace customized final quotes

The demo currently has 3 sample teachers.
